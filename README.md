# Закрома ремесленника

Памятка Telegram-канала [«дизайн ремесленник»](https://t.me/design_remeslo): полезные сайты, архивы, нейросети, библиотеки, мокапы, шрифты и эффекты для дизайнера в одном месте, с поиском и фильтрами по разделам.

Ссылки собраны из постов канала и таблицы «Полезные сайты и ИИ», проверены 26.10.2026.

## Как устроено

- `index.html` — сама страница, без сборки и зависимостей (шрифт Inter подключается с Google Fonts).
- `links.json` — все ссылки и разделы. Страница берёт данные отсюда.
- `img/` — превью сайтов и картинки из постов, 560×700 в WebP.

## Как добавить ссылку

Открой `links.json`, добавь в массив `items` объект и закоммить:

```json
{"n": "Название", "u": "https://example.com", "d": "Зачем она нужна", "s": "tools", "t": ["free"]}
```

- `s` — раздел: `refs`, `sites`, `archives`, `ai`, `td` (3D), `illus`, `mockups`, `tools`, `anim`, `tilda`, `learn`, `files`.
- `t` — метки: `free`, `freemium`, `paid`, `ai`.
- `img` (необязательно) — путь к превью, например `img/my-site.webp`.
- `p` (необязательно) — номер поста в канале.

Копия данных также зашита в `index.html` для мгновенной первой отрисовки; при открытии страница подтягивает свежий `links.json`.
